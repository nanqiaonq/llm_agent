# 课前准备：租 VPS + 申请域名

> 本文是《agent智能体上线与部署》开始前的手册，可对照执行。

---

## 目标读者与前置

本课面向已完成《主流Agent类型及接口设计》的学员，进课堂前你需要准备：

1. 一台能 SSH 进去的腾讯云 VPS（轻量云服务器）
2. 一个完成实名审核的国际域名
3. 域名能 `dig` 出 VPS 公网 IP

本文手把手带你在腾讯云平台租 VPS 把这三件事做完。

**顺序安排**：先教购买国内 VPS 熟悉腾讯云控制台流程 → 等域名审核期间申请域名 → 最后购买香港 VPS（含"一键配置域名解析"功能，需要域名先就绪才能用）。

## 一、两条路径选一条

腾讯云有两种 VPS 路径，选哪条决定整门课的形态。

### 路径 A — 国内免费 VPS（1 个月免费，需 ICP 备案）

- 个人实名认证后**免费试用 1 个月**
- 配置：2 核 / 2GB / 3Mbps / 40GB SSD / 200GB 月流量
- 仅限**大陆机房**（北京/上海/广州等）
- 试用期满后续费：2 核 2GB 3M 约 68 元/年，4 核 4GB 3M 新人价 38 元/年

**核心优势**：**如果只用 IP 直连访问、不要域名，1 个月试用期内 0 元成本**。适合做 demo、内部测试、给同事临时演示。

**限制**：要绑定域名做正式 HTTPS 上线，必须完成 **ICP 备案**——平台初审 1-2 工作日 + 通管局审核 ≤ 20 工作日，总计约 2-3 周。备案期间你的 80/443 端口被腾讯云拦着，网站对外不可访问。

来源：[腾讯云免费体验馆](https://cloud.tencent.com/act/pro/free) / [腾讯云 ICP 备案流程](https://cloud.tencent.com/document/product/243/18909)

### 路径 B — 香港付费 VPS（不用备案，直接 https://）

- 单月：38 元/月
- **包年：384 元/年**（约 32 元/月，常驻 80% 折扣价）
- 配置：2 核 / 2GB / 20Mbps / 40GB SSD / 0.5TB 月流量
- **不需要 ICP 备案**（机房在香港，工信部不要求）
- 大陆访问延迟约 30-50 ms（比北京机房高，但浏览体验完全 OK）

来源：[腾讯云轻量服务器价格总览](https://cloud.tencent.com/document/product/1207/73452) / [轻量服务器香港地域](https://cloud.tencent.com/product/lighthouse)

### 两条路径开销对比

| 项目 | 路径 A 国内 | 路径 B 香港 |
|---|---|---|
| VPS 试用 | 1 个月免费 | 38 元/月（无免费） |
| VPS 续费包年 | 68 元/年（2C2G） | 384 元/年（2C2G） |
| 域名首年 | 10 元（同） | 10 元（同） |
| **ICP 备案等待** | **2-3 周** | 0 |
| **大陆访问延迟** | 5-10 ms | 30-50 ms |
| **能接国内支付** | 备案后可以 | 不行 |
| **课堂走通时间** | 等备案完成后才行 | 1-2 天（卡在域名审核） |

### 课堂建议：选路径 B

**想配域名做 HTTPS 上线，选香港付费 VPS**。理由：

- 课堂时间紧，等不起 2-3 周备案
- 38 元/月 单月体验完整流程，比包年负担小
- 学完想继续用，再升包年 384 元/年也来得及

路径 A 适合"只想学一下 Linux部署但不涉及域名"的场景。本文先用国内 VPS 带你熟悉腾讯云控制台流程（章节二），再带你买香港 VPS 用于课堂正式部署（章节五）。

### 2.5 端口可达性测试

在 shell 里贴入下面的代码，启动一个最小 HTTP 服务监听 12234 端口：

```bash
python3 - <<'PY'
from http.server import BaseHTTPRequestHandler, HTTPServer
from datetime import datetime
import socket

PORT = 12234

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        html = f"""
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>腾讯云 12234 端口测试</title>
</head>
<body>
  <h1>12234 端口被你打通啦</h1>
  <p>主机名：<code>{socket.gethostname()}</code></p>
  <p>当前时间：<code>{datetime.now()}</code></p>
</body>
</html>
"""
        data = html.encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

server = HTTPServer(("0.0.0.0", PORT), Handler)
print(f"Serving on http://0.0.0.0:{PORT}")
server.serve_forever()
PY
```

回车后看到 `Serving on http://0.0.0.0:12234` 说明服务起来了。

![端口测试服务启动成功](https://typora-photo1220.oss-cn-beijing.aliyuncs.com/DataAnalysis/Leo/agent-deploy/2026-05-15/cn-step09-port-test-37abcd36.png)

腾讯云控制台 → 轻量应用服务器 → 立即购买。选择：

- 镜像：**Ubuntu 24.04 LTS**（不是 22.04，本课基线）

![购买海外服务器](https://typora-photo1220.oss-cn-beijing.aliyuncs.com/DataAnalysis/Leo/agent-deploy/2026-05-15/购买海外服务器-2179a10a.png)

### 5.2 一键配置域名解析

下单时勾选**"一键配置域名解析"**——这一步会在你购买完域名后自动把域名 A 记录指向你的新 VPS 公网 IP，省一步手动配 DNS。

![一键配置域名解析](https://typora-photo1220.oss-cn-beijing.aliyuncs.com/DataAnalysis/Leo/agent-deploy/2026-05-15/一键配置域名解析-5df9281d.png)

购买完成回到控制台「轻量应用服务器」列表，能看到这台机器和它的 **IPv4 公网 IP**（如 `43.129.193.131`）。

记下这个 IP，后面课堂里所有命令都用它。

### 5.4 首次 SSH 登录验证

控制台「登录」按钮可以直接打开网页终端，免密链接进系统。学员也可以本机用 ssh 命令登录：

```bash
ssh ubuntu@<你的VPS IP>
# 或如果买的镜像默认是 root: ssh root@<你的VPS IP>
# 用控制台设置的密码登录
```

进系统后跑一下：

```bash
whoami            # 期望 ubuntu 或 root
lsb_release -ds   # 期望 Ubuntu 24.04.x LTS
uname -r          # 期望 6.8.x（24.04 默认内核）
```

如果三个命令都正常输出，VPS 部分准备完成。

## 六、解析验证

域名审核通过后，如果购买香港 VPS 时勾过"一键配置域名解析"，腾讯云已经自动加好 A 记录指向你的 VPS IP。

本机验证：

```bash
dig +short myagent-lab.online
# 期望输出: 43.129.193.131（你的 VPS IP）

ping myagent-lab.online
# 期望: 收到 ICMP 响应，延迟约 30-100 ms
```

如果 `dig` 返回正确 IP，DNS 解析全链路通了。

如果没有勾过"一键解析"，控制台「我的域名 → 解析」手动加一条 A 记录：

- 主机记录：`@`（表示根域名）
- 记录类型：`A`
- 记录值：你的 VPS IP

10 分钟内全球生效。

## 七、ICP 备案（仅路径 A 国内 VPS 需要）

> 走章节五的香港 VPS（路径 B）可以跳过本章节。只有把域名解析到国内大陆机房 VPS（路径 A）才需要做 ICP 备案，否则腾讯云会拦截你 IP 的 80/443 端口对外访问。

### 7.1 6 步流程

国内 VPS + 域名搭配做 HTTPS 上线，必须完成工信部 ICP 备案。流程：

```
① 你备料                                      1-2 小时
   身份证扫件、域名证书、网站性质问卷、负责人手持身份证照
   ↓
② 腾讯云平台初审                              1-2 工作日
   材料完整性、格式合规、域名归属对得上
   ↓
③ 腾讯云推送工信部                            即时
   ↓
④ 工信部短信核验                              24h 内你必须回应
   你手机收到的短信里有验证码，必须 24 小时内完成核验
   ↓
⑤ 通信管理局复核                              ≤ 20 工作日
   网站性质、负责人实名、内容合规
   实测中位数 7-15 个自然日（看省份）
   ↓
⑥ 备案号下发 + 解除 80/443 拦截              即时
   收到短信和邮件 + 腾讯云自动放行你的 IP
```

**实测总时长**：2-3 周（中位省份）
**官方承诺上限**：4-5 周

### 7.2 备案完成后做的事

拿到备案号（形如 `京ICP备2026xxxxx号-1`）后：

- 腾讯云自动解除 VPS IP 的 80/443 拦截
- 网站底部必须显示备案号（工信部要求，未显示有违规风险）
- 后续课程内容（nginx / certbot / systemd 等）跟路径 B 完全一样

### 7.3 驳回常见原因

- 域名所有人 ≠ 备案主体（用朋友 ID 注册的域名）
- 网站性质选错（个人备案做电商内容 → 要改"经营性 ICP"）
- 短信核验超时（24h 内没回应）
- 服务器 IP 不是腾讯云的（在腾讯云备案但解析到阿里云）

驳回 = 重提一轮 = 再 +1-2 周。

来源：[腾讯云 ICP 备案流程](https://cloud.tencent.com/document/product/243/18909) / [腾讯云 ICP 备案常见问题](https://cloud.tencent.com/document/product/243/19650)

## 八、进课堂前的检查清单

打开终端，按顺序跑：

```bash
# 1. SSH 能登
ssh ubuntu@<你的VPS IP>
# 进得去就过

# 2. Ubuntu 版本对
lsb_release -ds
# 期望: Ubuntu 24.04.x LTS

# 3. DNS 解析对
exit
dig +short <你的域名>
# 期望: 返回你的 VPS IP

# 4. 域名可 ping 通

# 期望: 收到响应
```
