扩展层 · 8 种外部 Memory Provider

全部 opt-in  ·  hover 或聚焦卡片翻面查看特点

⚠️

默认链路 = 热双层 + 冷三件套 / 这 8 个 Provider 全部需在 ~/.hermes/config.yaml 显式启用

Honcho
辩证用户建模 / USER.md 自动填充器
⭐ 社区最推荐
Honcho
✨通过对话辩证推理用户特征（沟通/技能/习惯）
✨跨 session 累积"用户画像"
✨唯一能自动填 USER.md 的 Provider
👤适用：希望 Agent 越用越懂你
memory.provider: honcho
Mem0
向量 + 图 + 键值 三引擎
📊 48K stars / $24.5M
Mem0
✨三引擎并存：向量 + 图 + 键值
✨用户级 + 会话级 + Agent 级 三维记忆
✨AWS Strands SDK 独家 Provider
🎯适用：快速给 Agent 加"跨会话记忆"
memory.provider: mem0
OpenViking
纯向量后端
通用
OpenViking
✨简单纯向量数据库后端
✨无 lock-in / 自托管友好
🎯适用：轻量场景，不要图/键值复杂性
memory.provider: openviking
Hindsight
语义 + 图 混合
推理型
Hindsight
✨语义检索 + 知识图谱并存
✨支持记忆关系推理（"A 与 B 关系"）
🎯适用：复杂查询 / 研究分析场景
memory.provider: hindsight
Holographic
HRR 向量编码 + trust_score 奖惩
⚠️ 研究级 · 不在默认
Holographic
✨HRR 编码（多概念叠加在同一向量）
✨trust_score：记忆有可信度，错误降权
⚠️PDF 营销"四层记忆默认架构"原型 → 实际是 opt-in
🔬研究级，不建议生产使用
memory.provider: holographic
RetainDB
持久化记忆
稳定
RetainDB
✨简单纯持久化（无算法黑盒）
✨跨会话 + 长期保留
🎯适用：要稳定可预期，不要"AI 魔法"
memory.provider: retaindb
ByteRover
字节级回放
审计型
ByteRover
✨完整字节流记录（含中间状态）
✨历史会话可"回放"
🎯适用：audit / debug / Agent 行为复现
memory.provider: byterover
Supermemory
语义图 + context fencing
🆕 v0.8.0 新增
Supermemory
✨语义图存储
✨context fencing：自动隔离不同上下文（防记忆"串门"）
🎯适用：多项目 / 多领域 Agent
📅v0.8.0 (2026-04-08) 新增
memory.provider: supermemory
