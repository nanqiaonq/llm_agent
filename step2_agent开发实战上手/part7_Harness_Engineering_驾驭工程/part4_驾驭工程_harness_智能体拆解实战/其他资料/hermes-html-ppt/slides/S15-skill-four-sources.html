前三种来源均为"先有需求、后有 skill"；agent-created 对应 README 上那句 "creates skills from experience"—— 跑过几个 session 后执行 ls -la ~/.hermes/skills/，会看到你从未写过的 skill 目录（如 kafka-debugging），这就是 Nudge 的产物
