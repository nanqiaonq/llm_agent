第2章 · Prompt 驱动反思
Prompt 驱动反思：PATCH > CREATE + ACTIVE 倾向
_SKILL_REVIEW_PROMPT — Preference Order（写死在 prompt 里）
  • 1 PATCH 当前 session 用过的 skill — UPDATE A CURRENTLY-LOADED SKILL（优先级最高）
  • 2 PATCH 类别 umbrella skill — UPDATE AN EXISTING UMBRELLA（其次）
  • 3 添加支持文件 — ADD A SUPPORT FILE under an existing umbrella（再次）
  • 4 创建新 skill — CREATE A NEW CLASS-LEVEL UMBRELLA SKILL（最后）
"'Nothing to save.' is a real option but should NOT be the default."
prompt 主动鼓励产出而非沉默 — fork agent 倾向找到一个可以更新或创建的 skill
"Be ACTIVE — most sessions produce at least one skill update. A pass that does nothing is a missed learning opportunity."
_COMBINED_REVIEW_PROMPT 进一步强化 ACTIVE 倾向
⚠ 中度风险：ACTIVE 倾向导致 fork agent 倾向编造低质 skill — 需要 curator 定期合并去重
