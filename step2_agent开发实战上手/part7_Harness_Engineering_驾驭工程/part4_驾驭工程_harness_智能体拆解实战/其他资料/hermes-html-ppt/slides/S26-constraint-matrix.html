约束轴四维度对比

Hermes 三维弱一维强 · Claude Code 四维都强（代价：动态弱、仅单点 IDE）
约束维度 = agent 跑代码时被工程边界锁住的程度（高 = 安全但慢；低 = 快但押注信任）

Hermes

没有完美选择——每家都在「约束 ↔ 动态 ↔ 入口治理」三个工程问题上押了不同筹码
