第4章 · 收束与收尾
学员带走 4 件产物
对应「读源码 + 跑 demo + 用 3 问评价法 + 四维框架做取舍判断」三条学习主线的全部产出
01
Hermes 默认记忆系统架构图
热双层：MEMORY.md（Agent 自维护）+ USER.md（用户画像，需启用 Honcho）； 冷三件套：SQLite 持久化 + FTS5 双索引（unicode61 + trigram） + LLM 摘要层（异步并发 3 / 最大 5 / 失败 3 次重试 / 可降级 raw preview）； 扩展层 8 种 Provider 全部 opt-in，不在默认链路。
02
Nudge 机制源码 walk 笔记
计数器累加（memory: user-turn / skill: tool-iter）→ turn 末判定 → fork 子 agent 4 重约束（max_iter=16 / quiet_mode=True / toolsets=memory+skills / 防递归 interval=0）→ _SKILL_REVIEW_PROMPT 驱动反思（PATCH>CREATE，ACTIVE 倾向）→ _create_skill 五步校验 → 落盘 ~/.hermes/skills/<name>/SKILL.md。 不是 AI 自主学习，是 prompt 驱动的机械闭环。
03
本地可跑 MVP Demo 代码包
langchain 三件套：NudgeMiddleware（计数器 + turn 末判定 + fork 子 agent）+ @tool write_skill（落盘动作）+ create_agent(tools=[write_skill], middleware=[])（受限子 agent）； 配 5 轮真实 kafka 调试场景 + 三组 nudge_interval 改参实验（5 / 2 / 0）。
04
3 问评价法 + 四维评价框架
静态↔动态 / 信任↔约束 / 集中↔分治； 3 问（能力 / 风险 / 入口）↔ L1 三支柱（GC / AC / 入口治理）+ 第 4 维 CE，附前三节关键词映射； 下节课末尾用同一把尺横评 Claude Code / Codex / DeepAgents / OpenClaw 四家。
