⚠️ 踩坑预警：漏写这两行 → 子 agent 跑 16 步时自己累加计数器 → fork 子子 agent → 指数爆炸，几分钟内 API 配额烧光 + OOM
⚠️ API 配额烧光 / OOM / 进程卡死
Hermes 用「自研类的构造参数」表达约束；LangChain 用「组合 + 显式声明」表达约束。两种风格各有适用场景。
