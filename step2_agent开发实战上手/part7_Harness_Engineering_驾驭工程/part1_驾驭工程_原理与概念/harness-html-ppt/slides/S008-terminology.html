术语边界 + LangChain 三层架构

术语 是什么 解决什么 与 Harness 的关系
Agent
智能体 / 代理
 会用工具完成任务的软件实体 让 LLM 具备行动能力 Agent 是目标，Harness 是让目标能持续运行的工程系统
Scaffolding
脚手架
 prompt 到达模型前的组装层 让 LLM 的输入更可控 Scaffolding 是 Harness 的一部分（偏 context 装配层）
Framework
框架
 提供类库和抽象的开发工具包 让你不用从零写 LLM 调用链 Framework 是积木，Harness 是用积木搭出来的整车
Runtime
运行时
 负责执行 agent 逻辑的运行时引擎 让 agent 状态机在工业环境可运行 Runtime 是发动机，Harness 是发动机 + 底盘 + 传动
LangChain 产品线三层
Framework · 框架（LangChain）
→
Runtime · 运行时（LangGraph）
→
Harness · 驾驭（DeepAgents）
Harrison Chase 2025-10-25 博文："大多数工程师需要的不是 runtime，是一个能直接跑的 harness"
