同任务三模式演示

让差异从表格里跳出来

A 裸 API（GPT-5）
把"实现一个待办应用"的任务扔给裸 GPT-5。它会返回三块代码，但永远不会真的创建文件、运行测试、看到失败后自己改。它只是在对话框里写字。
B Code Interpreter
同样的任务，它会真的创建 .py 文件、运行 pytest、看到失败。但它没有访问你本地项目的能力，没有 git，也没有任何跨 session 的持久化。关闭窗口，所有进度清零。
C Claude Code
在你本地创建完整项目结构，写完代码跑 pytest，失败了就改，最后 commit 到 git，下次打开从 claude-progress.txt 接着跑。这就是 harness 的力量。

三个画面的差距，不是"模型变聪明了"，是"模型外面被加了一层肉眼看不到的工程系统"。
