第二章

失效坐标系

看 naive agent 如何以八种方式失效

接下来你会看到：
一段 ~100 行 的 naive agent——它没有任何 harness 保护，所有的 LLM + tool calling 就是教科书式的 while True + JSON schema。

然后我们会把它放到一个非常朴素的任务里："读一个 Python 测试文件、修 bug、跑 pytest 确认通过"。

这个任务在 Claude Code 里 2 分钟能做完，在 naive agent 里——你会看到它用三种不同的方式失效。
它们不是从天上掉下来的"最佳实践"，它们是被一次次实战教训打磨出来的工程经验。
