1
Agent Loop 四相循环
救 ①
Gather → Action → Verify → Iterate，硬性加上 max_iterations 和显式终止条件。
类比：驾校教练的四步口诀——看路况 → 踩油门 → 看前方 → 调整方向。教练给你定了"跑 10 圈必须停"的硬规则。
# for 循环代替 while True for i in range(MAX_ITER): context = gather_context(state) action = take_action(context) result = verify(action) state = iterate(state, result) if state.is_done(): break
2
Tool Use 工具编排
救 ④
所有工具调用包裹在结构化 schema 里，失败时返回 {"status": "error"}，不是空字符串。
类比：USB-C 接口——host 能读到设备身份、能力、故障码；不兼容也返回"设备不识别"，而非死线静默。
try: result = TOOL_REGISTRY[tool_name](**kwargs) return {"status": "ok", "result": result} except Exception as e: return {"status": "error", "error": str(e)}
