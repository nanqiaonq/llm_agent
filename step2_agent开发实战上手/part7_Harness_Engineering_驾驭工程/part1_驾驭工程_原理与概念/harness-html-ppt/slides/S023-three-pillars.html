Context Engineering
输入端
怎么在第一时间把对的资料喂给它
Agent 能"看见"什么？
Claude Code 三例
  • CLAUDE.md：项目目录级 RAG system prompt
  • session compaction：长会话自动压缩上下文
  • progress 文件：把进度落盘，跨 session 续传
本质：整理 agent 看见的信息
代表机制：Context Management · Feature List · Progress Tracking · Subagents

Architectural Constraints
控制流
它发疯的时候，你怎么硬生生按住它
Agent 能"做"什么？
Claude Code 三例
  • 27 种 hook：在工具调用前后插入约束
  • Permission Gate：危险操作必须人工确认
  • Task tool / subagent：分治隔离，主 context 不污染
本质：设红线、拉电闸，约束 agent 能做什么
代表机制：Agent Loop · Tool Use · Verification Loop · Generator-Evaluator

Garbage Collection
状态流
内存快被撑爆时，怎么有策略地遗忘
Agent 能"跑多久"？
Claude Code 三例
  • token budget：防爆预算，超阈值强制收敛
  • session compaction：回收过期上下文
  • compaction → reset：Anthropic 2025→2026 路线
本质：容错与动态收敛，策略性遗忘
代表机制：Context Management（辅）· Feature List（辅）· Subagents（辅）· Token Budget（第二节补）
三支柱不是单一作者原创，是综合 Martin Fowler 系 / Anthropic / Phil Schmid 多来源抽象的工程维度框架——Claude Code 把三柱全部落成可见实现。
