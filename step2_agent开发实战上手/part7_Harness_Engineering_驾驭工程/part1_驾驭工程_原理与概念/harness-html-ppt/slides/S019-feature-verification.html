7.5 Feature List + 7.6 Verification Loop
5
Feature List 任务拆解
救 ②源头
大任务拆成 JSON 清单，强制 agent 单次迭代只做一件事，做完标记再取下一件。
类比：Trello 看板——每张卡片有 pending / in_progress / passes 状态，是 agent 的外置工作记忆。
features = [ {"id":1, "task":"读文件", "status":"pending"}, {"id":2, "task":"修bug", "status":"pending"}, ] def get_next_task(features): return next( (f for f in features if f["status"]=="pending"), None)
6
Verification Loop 验证闭环
救 ④下游
每个 feature 完成后用 pytest / Playwright 真机验证，通过才标记 passes=true。
类比：QA 验收测试——开发说"修好了"不算数，QA 真的点按钮、跑场景才算数。
def verify_with_pytest(): result = subprocess.run( ["pytest", "--tb=short"], capture_output=True, text=True) return { "passed": result.returncode==0, "output": result.stdout + result.stderr}
