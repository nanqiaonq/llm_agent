八大故障模式清单

本课最重要的记忆载体——30 秒内背出来

1 循环失控
现场：while True 或无终止验证
后果：API 额度耗尽、资源无限占用
2 Context 溢出
现场：messages 无限 append
后果：超 window 报错、token 费用失控
3 Cache Miss
现场：前缀在循环内被改动
后果：延迟翻倍、费用翻倍
4 Tool 错误吞
现场：except 吞异常或丢 returncode
后果：在错误基础上继续操作
5 状态丢失
现场：无 progress 文件
后果：session 关闭全丢，无法续传
6 缺权限闸
现场：rm -rf / sudo 直接执行
后果：数据毁损、生产事故
7 缺自动化评审
现场：agent 自评无第三方把关
后果：发现问题时产物已交付
8 成本失控
现场：无 token budget
后果：长任务耗尽月度 API 预算
学习钩子：从下一节开始，每当看到一个新机制，先问自己"它救的是哪一条？"
