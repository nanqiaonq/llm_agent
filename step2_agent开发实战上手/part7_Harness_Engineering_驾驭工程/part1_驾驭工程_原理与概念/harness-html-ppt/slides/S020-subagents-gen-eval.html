7
Subagents 子代理分治
救 ②另一解
把子任务派发给独立 context 的子 agent，完成后只把结果返回主 agent，主 context 不受污染。
类比：外包给顾问——CEO 把专业问题外包，顾问独立项目做几周，只交结论给 CEO。CEO 的主 context 没被中间文档污染。
def subagent(task, tools): # 独立 messages，不共享主 agent 历史 sub_msgs = [ {"role":"system", "content":"专注单一子任务"}, {"role":"user", "content": task}, ] # 内部跑完整 loop，外部看不到中间步骤 return run_loop(sub_msgs, tools)
8
Generator-Evaluator 生成-评估对抗
救 ⑦
Planner 拆任务 + Generator 写代码 + Evaluator 独立评审。Evaluator 不看过程，只看最终产出。
类比：论文评审——作者写论文，审稿人只看论文本身打分；编辑协调修改方向。三角色分离才能保证质量。
