生态雷达：四系家族
10+ 主流 Harness 产品的工程架构归类——每系都有自己的使用场景和典型踩坑
🖥
CLI-first 命令行系
终端
长任务放进去，走人泡咖啡回来看成果
  • 最擅长：长任务自主运行、脚本化流水线、CI/CD 集成
  • 典型踩坑：无人值守时错误被吞没；中间状态不可见
  • 适合场景：批量改造、autorun 迁移、夜跑任务
代表：Claude Code · Codex CLI · Amp · Aider
🧩
IDE-native 客户端系
编辑器
边写边改，光标在哪它就在哪
  • 最擅长：行内补全、diff 可视化、即时 accept/reject
  • 典型踩坑：交互密集导致 context 碎片化；大范围改动受限
  • 适合场景：日常写代码、pair programming、轻量重构
代表：Cursor · Windsurf · GitHub Copilot Chat
☁
Cloud-Sandbox 云端沙盒系
云端
给它一个云上的房间，钥匙你拿着
  • 最擅长：全托管环境、隔离安全、异步长任务
  • 典型踩坑：冷启动慢；本地文件上云合规复杂
  • 适合场景：企业合规、远程 agent、跨设备协作
代表：Devin · Replit Agent · E2B
📦
SDK-Harness 库系
库
不给现成产品，给你积木自己搭
  • 最擅长：深度定制、嵌入自有产品、研究原型
  • 典型踩坑：要自己实现 observability；学习曲线陡
  • 适合场景：构建自有 agent 产品、研究实验
代表：DeepAgents · LangGraph · AutoGen
