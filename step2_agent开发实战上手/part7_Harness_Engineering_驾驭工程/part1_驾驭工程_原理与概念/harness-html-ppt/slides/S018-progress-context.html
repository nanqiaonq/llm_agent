Progress Tracking 进度追踪
救 ⑤
每步进度写到持久文件 + git commit，session 断了能从断点续传。
类比：游戏存档——每过一个小任务自动存档，断了能"读档"接着跑。
def save_progress(state): PROGRESS_FILE.write_text( json.dumps(state, indent=2)) def load_progress(): if PROGRESS_FILE.exists(): return json.loads( PROGRESS_FILE.read_text()) return None

Context Management 上下文管理
救 ②③

类比：工位清理——文件堆到爬不动时，归档成摘要或从空桌开始；但工位名牌（system prompt）永远不动。
