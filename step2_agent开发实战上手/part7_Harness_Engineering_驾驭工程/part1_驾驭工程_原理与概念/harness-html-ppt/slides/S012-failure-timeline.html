naive agent 失效时间线
从启动到崩溃，8 个故障按发生顺序排列
1
循环失控
第 1 轮
while True 无终止验证，模型以为任务没完一直跑，API 额度无限消耗。
2
Context 溢出
第 3 轮
messages 无限 append，轮次越多 prompt 越长，Token 费用失控。
3
Cache Miss
每轮触发
system prompt 每轮被改写，前缀不稳定导致 prompt cache 全部作废，延迟翻倍。
4
Tool 错误吞
第 2 轮
except 吞掉异常返回空字符串，agent 以为成功，继续在错误基础上操作。
5
状态丢失
Session 结束
无 progress 文件，关闭窗口后所有进度清零，长任务无法跨天续传。
6
缺权限闸
任意时刻
无 Permission Gate，rm -rf / sudo 可直接执行，数据毁损、生产事故。
7
缺自动化评审
任务完成时
agent 自己说"做完了"就退出，没有独立 Evaluator 把关，发现问题时产物已交付。
8
成本失控
全程累积
无 token budget，循环跑多久 API 烧多少，一个长任务可能耗尽整月预算。
