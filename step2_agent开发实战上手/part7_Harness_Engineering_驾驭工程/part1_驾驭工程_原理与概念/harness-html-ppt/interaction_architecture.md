# 交互架构决策文档

## 全局交互策略
- 导航：左右箭头 + 键盘方向键 + 侧边菜单章节分组
- 画笔：T 键轨迹（2秒淡出）、D 键画板、颜色选择器
- 全屏：F 键
- 菜单：M 键

## 交互组件清单

### 🔴🔴 组件需求
1. **代码高亮+故障弹窗**（S010）：行内故障编号badge，hover/click弹出故障详情tooltip
2. **时间轴节点**（S013）：水平时间轴，8个节点可点击，点击展开节点详情面板
3. **四相循环动画**（S017）：SVG/CSS四相循环，当前相位高亮，点击相位切换详情
4. **三角色切换**（S020）：Planner/Generator/Evaluator三角色卡片，点击切换当前角色视角
5. **矩阵hover高亮**（S022, S024）：8×8和8×3矩阵，hover单元格高亮整行整列
6. **三支柱动态连线**（S023）：三柱到8机制的SVG贝塞尔曲线连线，依次动画出现
7. **生态雷达**（S026）：四象限雷达图，11+产品点分布，hover显示产品信息
8. **知识图谱辐射**（S030）：中心节点到四组子节点的SVG动态连线，依次辐射展开

### 🟡 组件需求
1. **渐进揭示表格**（S003）：表格行依次fade-in出现
2. **同心圆动画**（S007）：三层同心圆依次scale-in
3. **staggered卡片**（S002, S016）：卡片依次出现，hover微抬升
4. **数字计数动画**（S014）：大数字从0计数到目标值
5. **对比分栏**（S018, S019）：左右/上下分栏，hover高亮当前侧
