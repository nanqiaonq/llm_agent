三个操作：Ingest / Query / Lint

点选操作——查看它对每一层的读写权限

Ingest
编译 · 写 wiki
读 raw/ 新原料，按 schema 在 wiki/ 编译互链页，更新 index.md 与 log.md
Query
查询 · 只读 wiki
只读 wiki/，从 index.md 导航定位相关页，给出带引用的回答，不重读 raw/（前提：wiki 已由最新 raw ingest）
Lint
巡检 · 只读检查
检查 wiki 一致性（断链 / 孤儿页 / 过期内容），只产出问题报告，不写任何层
raw/
原料层 · 人类拥有
事实源头，编译的输入。Agent Ingest 时只 Read 不 Write；人类可更新 raw，更新后需重新 Ingest。 编译期 raw 不变，是整个范式可信的地基。

wiki/
知识层 · LLM 拥有
编译产物，由 LLM 增删改的互链页面（包含 index.md 与 log.md）。 Ingest 写、Query 读、Lint 检查——是三个操作最活跃的战场。

CLAUDE.md
规则层 · 人类撰写
schema 立规矩，约束 LLM 怎么编译。定义页面命名 / 链接语法 / 三操作边界。 LLM 只 Read 不 Write——执行前读规则，不修改规则本身。

三个操作就是编译式 RAG 的全部交互词汇：Ingest（编译知识）· Query（查询结论）· Lint（巡检一致性）。 读写边界是整套范式可信的制度保证。
