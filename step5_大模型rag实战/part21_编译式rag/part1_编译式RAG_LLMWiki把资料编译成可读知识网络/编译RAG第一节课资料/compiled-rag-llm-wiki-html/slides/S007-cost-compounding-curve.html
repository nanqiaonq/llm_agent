知识：从一次性消费到复利资产

累计查询次数增加时两种范式的理论成本走向——注意"复利"指知识结构复用，不等于单次查询省 token

解释执行（传统 RAG）——每次查询都重新消化，成本线性上升
编译执行（编译式 RAG）——前置编译成本，之后查询成本趋平
→ 查询次数越多，前置编译成本摊得越薄（理论示意，token 真实成本见第 13 页）
解释执行：成本随查询线性增长
每次查询独立付出「检索 + 拼 prompt + 归纳」的消化成本，知识不沉淀，成本不摊薄，累计成本随查询次数线性上升。
编译执行：前置编译后查询趋平
编译期一次性付出较高成本，把知识固化为可复用的 wiki——这是"知识结构复用"意义上的复利。但要注意：它并不等于单次查询 token 更低（真实数据见第 13 页，编译式查询反而约 20× 更贵）。
⚠ 以上为理论成本趋势曲线（示意模型）——第 13 页将用真实实测数据打脸：编译式查询约 20× 更贵，「省成本」需要具体语境。
