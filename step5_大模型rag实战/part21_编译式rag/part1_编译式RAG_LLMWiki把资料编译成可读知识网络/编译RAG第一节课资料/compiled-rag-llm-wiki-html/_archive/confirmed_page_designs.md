> 配色：g1-moon-slate（月白灰蓝），目录已定宝蓝 #2F5BC5。

| 页 | 标题 | 选定展现形式 |
|---|---|---|
| S01 | 封面 | **隐喻符号型**：标题 + `[raw] →〔编译〕→ [wiki]` 视觉箭头 + 点题句"把每次重查变编译一次" |
| S02 | 你大概率见过的别扭 | **场景对话型**：你问→系统答→同问再问→系统又从头检索，对话气泡呈现"每次都重新开始、从不沉淀" |
| S03 | 答案抖动 🔴 | **双答案对比+三层归因**：点"再问一次"并排出两次答案、高亮不同处，下方标注检索/排序/生成三层随机源 |
| S04 | 索引滞后 🔴 | **改数字即时演示**：源文档价格数字可亲手改→索引快照不变→查询仍命中旧值，三段联动 |
| S05 | 共同根因 | **两病归一型**：答案抖动+索引滞后两箭头汇到"同一根因（每次从头消化、知识不沉淀）"，再引出追问 |
| S06 | 编译vs解释（同源分叉模拟器）🔴🔴 | **2026-06-16 用户二次拍板重构**（初版"上下双轨·水平推进"未体现编译形态转变，已弃）：**同源分叉·两种命运**——顶部共同 raw 原料（只读·0改动·常驻）→ 提问后分叉两路：左路解释执行从头重走 检索→拼prompt→临时归纳、答案每次抖动、用完即焚（淡出）；右路编译执行首次把 raw 碎片凝聚成绿色互链 wiki 产物盒（[[链接]]·永久复用·常驻），之后秒回同一份；底部非对称累计计数器（左：重走N次/N个不同答案✗ vs 右：编译1次/秒回N次/同一份✓）。第一性原理：编译=形态转变+一次前置+反复复用的非对称。**2026-06-16 framing 修正**：「一个相同问题」→「一类问题（换问法/追问）」——「相同问题秒回」会把右路矮化成普通缓存，丢掉编译≠缓存（§1.3）的核心卖点；改后左路每轮显示具体问题标签（Q1真省成本吗/Q2和缓存啥区别/…）、这类问题每个都重走「零复用」，右路换啥问法都命中「1 份产物覆盖 N 个问题·一次编译全类复用」。抖动痛点归 S03、本页主轴=复用 vs 重走 |
| S06b | 解释执行内在过程（逐个算相似度）🔴 | **2026-06-16 重做**（用户批「只显示召回结果、没显示 embedding 计算机制」，第一性原理重选→「相似度逐项计算条」）：展示匹配的**计算过程**——本问→向量化→q，与向量库 6 个 chunk 逐个算余弦相似度，横条显示分数分布、top-3 高亮召回；换问题→问题向量变→6 个 cos 全部重算→top-3 重排（实测 Q1 成本0.89/20×0.86 ↔ Q3 纪律0.90/所有权0.85 完全不同）。忠于 lesson §27/§190。第一性原理：不同问题=不同问题向量=不同相似度分布=不同召回 |
| S06c | 编译执行内在过程（index 目录导航命中）🔴 | **2026-06-16 重做**（用户批「只显示命中、没显示怎么命中」，第一性原理重选→「index.md 目录导航+链接扩展」）：展示 lesson §1.4/§2.5/§3.8 的**真实命中机制**——agent 读 index.md 目录定位入口页（不向量化、不碰 raw）→ 沿 [[链接]] 扩展关联页（SVG wiki 互链图高亮路径）→ 读已提炼结论；换问题→命中不同目录条目→不同入口/不同链接路径（Q1→证伪实验+link-if / Q2→概念基础+link-ci）。第一性原理：编译执行=有目录直接导航「查」 vs 解释执行无目录只能向量「猜」。**命中主体=LLM agent**（用户追问澄清）：读 index.md 目录、凭语义理解判断该读哪几页——非关键词匹配、非向量检索（lesson §3.8 system_prompt「先看 index.md 导航定位相关页」+ Read/Grep 只读工具）；页面已加 🤖 agent 机制说明条点透 |
