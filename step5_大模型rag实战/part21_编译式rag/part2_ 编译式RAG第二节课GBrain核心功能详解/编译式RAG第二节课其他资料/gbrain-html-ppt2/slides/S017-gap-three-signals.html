能力二：读+想

空白分析 gap：最该先看的

think 诚实告诉你还不知道什么——三类信号，先看缺口再看正文

⚠
think 输出末尾的 gap 分析才是差异化价值所在——正文告诉你"已知的"，gap 告诉你"未知的"
SIGNAL 01
🕐
过期信息
某页数据上次更新已超过合理时效——比如半年前记录的融资进展，对方可能已完成新一轮或换了方向。GBrain 对照页面时间戳与当前日期标记此类风险。
你该做什么
去核实最新情况，别拿旧数据做决策；必要时重新 import 更新后的笔记
SIGNAL 02
⚠
无引用论断
某个结论在答案中出现，却找不到对应的支撑页面——模型可能在"脑补"而非从知识库引用。这类论断没有 [citation] 标注，最容易被误认为有据可查的事实。
你该做什么
保持警惕，不要直接复用；若重要则回溯原始资料手动核实
SIGNAL 03
⇋
自相矛盾
两页笔记对同一事实描述不一致——例如 A 页说"已完成 A 轮"，B 页还标注"种子轮阶段"。GBrain 检测到冲突后在 gap 段诚实列出，不擅自选边站。
你该做什么
人工判断哪条更可信，或将两条都标为"存疑"，更新知识库后重跑
养成习惯：先读末尾 gap 分析，再看正文综合答案。gap 数为 0 才是真的"安全出发"。
