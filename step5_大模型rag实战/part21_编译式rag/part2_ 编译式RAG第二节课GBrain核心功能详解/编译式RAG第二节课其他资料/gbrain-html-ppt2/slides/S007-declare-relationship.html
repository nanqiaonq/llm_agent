能力一：建图 self-wiring

建图的起点：你怎么声明关系

关系是你在 markdown 里显式写的，不是机器猜的

people/alice.md
--- name: Alice Chen role: Co-Founder & CEO works_at: [[companies/nexaflow]] --- # Alice Chen Alice founded [[companies/nexaflow]] in 2021. She advises [[companies/alphaventures]] on AI strategy. Bob works_at [[companies/nexaflow]] as CTO.
<!-- wikilink [[...]] = 节点；动词 = 边类型 -->
如何读这段 markdown
[[wikilink]] = 节点引用
双方括号 [[companies/nexaflow]] 告诉 GBrain：这里有一个指向另一个页面的显式链接。
GBrain 扫描后知道：Alice 和 NexaFlow 之间存在关系。
语义动词 = 关系类型
founded / advises / works_at 这些措辞告诉 GBrain 关系的方向和类型。
不是 LLM 猜测——是你写在正文里的，确定可审计。
四种关系类型
founded · works_at · invested_in · advises
GBrain 用正则规则把这四类解析成有向边，零 LLM，确定性，每条边都能溯源到你写的那一行。
关系是你显式写的，不是机器猜的——这是 self-wiring 与传统 LLM 知识图谱的根本区别，也是"零 LLM 零成本"的前提
