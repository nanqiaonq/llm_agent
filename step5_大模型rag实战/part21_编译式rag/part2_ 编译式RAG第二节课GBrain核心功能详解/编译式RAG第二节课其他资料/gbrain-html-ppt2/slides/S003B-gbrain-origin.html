思想原点
LLM Wiki
Andrej Karpathy
一篇只有概念、不含代码的 GitHub Gist。主张：别每次从零检索，让大模型把资料「编译」成结构化、互相链接的 markdown，查询直接命中复利积累的产物。
有意保持抽象——目录结构、schema、工具选择都留给读者和 Agent 自己落地。这正是本系列所称「编译式 RAG」的思想原点。
