让大脑认识知识类型，夜间自动打扫维护

schema 包
大脑认识知识的"词汇表"

schema 定义节点类型——告诉 GBrain 这个 wiki 页是 person、company 还是 project。有了类型，图谱才能按语义分类检索，而不是一视同仁的文本堆。

person
人物
company
公司/组织
project
项目
document
文档/笔记
meeting
会议
note
笔记/想法

类型存于 CLAUDE.md 规则层，改类型定义就改大脑的"认知边界"——无需重构代码，只需改规则文件。

🌙 Minions — 夜间自动维护
图谱的"清洁工"，你睡它干活

Minions 是一组后台任务，在你不用 GBrain 时自动运行。它们保持图谱健康、消除冗余、修复断链，让知识库越用越干净而不是越用越乱。

⍈
去重合并 (Dedup)
发现"同一实体多个页面"时合并为单一权威节点，消除图谱中的冗余分身
🔗
修复引用 (Re-link)
检测 wikilink 指向已改名/已删除页面，自动更新引用路径，防止边悬空
⚠
矛盾检测 (Conflict)
同一实体属性前后矛盾时标记，在 gap 分析中浮出"自相矛盾"信号供人工确认
↻
夜间持续循环 · 每轮改写后自动重跑 · 图谱常保健康
