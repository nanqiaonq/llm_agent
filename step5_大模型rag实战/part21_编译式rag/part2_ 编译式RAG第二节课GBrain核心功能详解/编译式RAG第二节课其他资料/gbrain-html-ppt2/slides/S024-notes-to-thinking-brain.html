从笔记到会思考的大脑

连得起来，也想得明白——你带走的是一把判断的尺

▶ 能力一 · 建图 Connect
self-wiring：零 LLM 把知识连起来
关系来自你在 markdown 里显式写下的 wikilink，不是机器猜的
零 LLM、零成本，正则解析 → typed 图谱，结果确定可复现
改一行 markdown，图谱跟着变；每条边都能溯源到来源行
Minions 夜间自动去重、修引用、检测矛盾，图谱常保健康
▶ 能力二 · 读+想 Read & Think
混合检索 + think 综合出有据可查的答案
HNSW + BM25 + RRF 三路合流，检索质量 R@5 = 97.6%
search 给页面列表；think 替你读完跨页综合成带引用成文答案
gap 诚实告诉你还不知道什么：过期信息 / 无引用论断 / 自相矛盾
约 21× token 是多跳综合的代价，换来可读可溯源的知识库
📏
你真正带走的：一把判断的尺
刻度 1 · 存储层
知识怎么存？
源真相在 git markdown；编译产物在数据库；改左≠自动追右，需重编译
刻度 2 · 检索层
benchmark 诚不诚实？
口径（R@5 vs P@5）/ 数据集（公开 vs 厂商自建）/ 判题方式（规则 vs LLM judge）严禁混引
刻度 3 · 综合层
成本值不值？
稳定知识 + 需跨源深综合 → think 划算；高频简单查询 → search 更合适

GBrain 是一个完整的 brain layer——两大能力缺一不可：连得起来才能溯源，想得明白才能给答案。
拿这把尺去拆任何 RAG/记忆系统，你就知道它在哪一层做了什么、做得怎么样。
