开篇与背景

三层 + 三操作骨架

GBrain 用三层存储组织知识，三个操作驱动整个循环

三层存储结构
raw/
原料层 · 只读，永不修改
你的原始笔记、文档、素材，GBrain 只读不改
wiki/
产物层 · LLM 维护的可读输出
编译后的结构化页面，可直接读取；查询时 GBrain 读的是这里
CLAUDE.md
规则层 · 行为约束
告诉 LLM 维护 wiki 的规则与约定，Lint 据此检查
三层全展 · 三操作循环已激活
三个操作 · 循环驱动
I
Ingest
读取 raw/ 原料，编译写入 wiki/ 产物；触发关系抽取和图更新
↓
Q
Query
检索 wiki/ 产物，综合给出带引用答案和空白分析（gap）
↓
L
Lint
依 CLAUDE.md 规则检查 wiki/ 质量；去重、修引用、检矛盾
↻  Ingest → Query → Lint → Ingest · 持续循环驱动
