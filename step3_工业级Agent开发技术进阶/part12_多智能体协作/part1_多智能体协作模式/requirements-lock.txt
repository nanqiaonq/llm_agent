# ✅ 安装方式(一个环境跑全本,无需切换 kernel):
#   python3.12 -m venv .venv && source .venv/bin/activate
#   pip install -r requirements-lock.txt --no-deps

#
# ⚠️ 为什么必须加 --no-deps:
#   本课横跨 5 个框架(LangGraph / CrewAI / OpenAI Agents SDK / MAF / Claude SDK)。
#   CrewAI 1.14.6 把 opentelemetry 钉死在 1.34.x、把 pydantic 钉在 <2.13,而 MAF 要 otel 1.39+,
#   pip 直接做依赖求解会判定冲突报 ResolutionImpossible。但实测 CrewAI 在 otel 1.42 / pydantic 2.13
#   上照常运行——它的钉法过严而已。--no-deps 跳过求解、按下面的确切版本直接装,
#   5 个框架即可共处一个环境、整本 notebook 一个 kernel 跑通(全部代码实测验证)。
