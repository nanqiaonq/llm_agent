案例拆解：查天气的 TAO 两轮循环

假设用户对 Agent 说："帮我查一下北京今天的天气，如果气温超过 30°C，就提醒我带防晒霜。"

第一轮 · Think
识别需求，决定调用
get_weather
→
第一轮 · Act
调用：
get_weather("北京")
→
第一轮 · Observe
返回：
{temp:33,晴}
↓ 进入第二轮
第二轮 · Think
33°C > 30°C
触发高温提醒
→
第二轮 · Act
生成最终回答
追加出行建议
→
第二轮 · Observe
任务完成 ✅
循环终止
