ReAct Prompt（简化教学版）

左侧是可直接教学的简化提示词，右侧标注每段约束负责什么。

react_prompt.py
react_prompt = """ 你按 ReAct 循环工作：思考 → 行动 → 观察，最后给出回答。 思考: 先说明你下一步要做什么。"""
"""行动: 从工具中选择一个并给出参数。 可用工具: - calculate: 表达式 - wikipedia: 关键词"""
"""观察: 读取工具返回结果；若信息不足，可继续下一轮思考/行动。"""
"""回答: 仅基于观察结果输出最终答案。 输出格式固定为： 思考: ... 行动: ... 观察: ... 回答: ... """
思考约束
限制模型先做计划，不直接胡乱回答。
行动约束
必须明确“调用哪个工具 + 什么参数”。
观察约束
强制读取外部结果，避免闭门推理。
回答约束
最终结论只能来源于观察到的事实。
这版提示词刻意简化，目的是让学员先掌握 ReAct 范式，再过渡到 Funcation Calling 的结构化实现。
